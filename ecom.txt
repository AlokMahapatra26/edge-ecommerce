4. DATABASE SCHEMA (CLOUDFLARE D1 / SQLITE + DRIZZLE ORM)
--------------------------------------------------------------------------------
- users
    id (TEXT / UUID, PRIMARY KEY)
    email (TEXT, UNIQUE)
    role (TEXT: 'customer' | 'admin')
    created_at (TIMESTAMP)

- categories
    id (INTEGER, PRIMARY KEY AUTOINCREMENT)
    name (TEXT)
    slug (TEXT, UNIQUE)

- products
    id (TEXT / UUID, PRIMARY KEY)
    category_id (INTEGER, FOREIGN KEY)
    title (TEXT)
    slug (TEXT, UNIQUE)
    description (TEXT)
    base_price (INTEGER in cents/paise)
    is_active (BOOLEAN)
    created_at (TIMESTAMP)

- product_variants
    id (TEXT / UUID, PRIMARY KEY)
    product_id (TEXT, FOREIGN KEY)
    sku (TEXT, UNIQUE)
    title (TEXT, e.g., "Black / XL")
    price_override (INTEGER, nullable)
    inventory_quantity (INTEGER)

- product_images
    id (TEXT / UUID, PRIMARY KEY)
    product_id (TEXT, FOREIGN KEY)
    r2_key (TEXT)
    display_order (INTEGER)

- orders
    id (TEXT / UUID, PRIMARY KEY)
    order_number (TEXT, UNIQUE)
    customer_email (TEXT)
    shipping_address_json (TEXT)
    subtotal (INTEGER)
    discount_amount (INTEGER)
    shipping_fee (INTEGER)
    total_amount (INTEGER)
    payment_status (TEXT: 'unpaid' | 'paid' | 'refunded')
    fulfillment_status (TEXT: 'pending' | 'processing' | 'shipped' | 'delivered')
    stripe_session_id (TEXT)
    tracking_number (TEXT, nullable)
    created_at (TIMESTAMP)

- order_items
    id (TEXT / UUID, PRIMARY KEY)
    order_id (TEXT, FOREIGN KEY)
    product_id (TEXT)
    variant_id (TEXT)
    title (TEXT)
    unit_price (INTEGER)
    quantity (INTEGER)

- coupons
    code (TEXT, PRIMARY KEY)
    discount_type (TEXT: 'percent' | 'fixed')
    value (INTEGER)
    min_order_value (INTEGER)
    max_uses (INTEGER)
    used_count (INTEGER)
    expires_at (TIMESTAMP)

5. ASYNCHRONOUS ARCHITECTURE (HOW ORDERS FLOW ON CLOUDFLARE)
--------------------------------------------------------------------------------
1. Customer clicks "Pay Now" -> Cloudflare Worker creates Stripe session.
2. Customer pays on Stripe -> Stripe fires a Webhook to:
   POST https://yourstore.com/api/webhooks/stripe
3. Cloudflare Worker verifies the webhook signature and immediately pushes
   the event into a `Cloudflare Queue` (returns 200 OK instantly to Stripe).
4. Cloudflare Queue Consumer (Worker background process):
   - Updates order status to 'paid' in Cloudflare D1
   - Reduces inventory in `product_variants`
   - Dispatches order confirmation email via Cloudflare Email
5. No dropped orders, no timeouts, resilient to traffic surges.
